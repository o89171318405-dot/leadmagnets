Расширенный гайд по сайтам с ИИ

Собери продуманный сайт руками ИИ

От брифа и визуального направления до чистого интерфейса, адаптивности и аккуратных анимаций. Внутри — инструменты, команды и правильный порядок работы.

✦
Что понадобится

Рабочая основа

  • Компьютер с Терминалом: Windows, macOS или Linux
  • Claude Code или другой coding-агент, который поддерживает Skills
  • Node.js LTS для установки инструментов через npm и npx
  • Тексты, фотографии, ссылки и задача будущего сайта
Что получится

Сайт с едиными правилами

  • Логичная структура страницы под конкретную аудиторию и действие
  • DESIGN.md с цветами, шрифтами, сеткой, отступами и компонентами
  • Интерфейс, проверенный по композиции, адаптивности и доступности
  • Анимации, которые помогают чтению и навигации
  • Код проекта, который можно дорабатывать и размещать на выбранном хостинге

Время зависит от объёма сайта, готовности материалов и количества правок. Установка инструментов занимает несколько минут, а сборка полноценной страницы требует отдельной работы.

✦
Базовая настройка

Подготовь рабочую среду

1
Установи Claude Code

Claude Code — coding-агент Anthropic: он читает проект, меняет файлы и запускает команды.

  1. Открой официальную документацию Claude Code
  2. Для Windows открой PowerShell и запусти рекомендованный установщик:
Windows PowerShell
PS> irm https://claude.ai/install.ps1 | iex
На macOS, Linux и WSL используется команда из официальной документации. Установщики меняются, поэтому бери актуальную команду только там.
2
Создай папку проекта

Все инструкции, DESIGN.md, исходники и установленные навыки должны относиться к одному проекту.

  1. Создай отдельную папку и открой её в VS Code
  2. Запусти Claude Code из этой папки:
Terminal
$ cd путь-к-проекту
$ claude
Библиотеку анимаций выбирают после определения стека. Для React агент может предложить Motion, а для простого HTML часто хватает CSS.
3
Установи Taste Skill

Навык design-taste-frontend помогает Claude удерживать выбранное визуальное направление, композицию, типографику, плотность и характер движения.

  1. Открой терминал в корне проекта
  2. Запусти официальную команду репозитория:
Terminal
$ npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"

Открыть репозиторий Taste Skill

Текущая версия основного навыка v2 помечена разработчиком как экспериментальная. Для стабильного старого поведения в репозитории оставлен вариант design-taste-frontend-v1.
4
Добавь компоненты при необходимости

21st.dev содержит готовые UI-компоненты. Используй их точечно, когда они подходят задаче и стеку проекта.

  1. Перейди на 21st.dev
  2. Выбери компонент и открой инструкцию установки
  3. Передай команду Claude Code и попроси адаптировать компонент под DESIGN.md:
Claude Code
> Установи выбранный компонент и приведи его к правилам из DESIGN.md. Сохрани адаптивность и доступность.

Рабочая среда готова. Теперь начинается проектирование сайта.

✦
Сначала смысл

Дай агенту нормальный бриф

Skill улучшает решения, но не придумывает бизнес-задачу вместо владельца. До дизайна зафиксируй 7 пунктов:

  • Кто открывает сайт и с какой проблемой
  • Какое действие должен совершить посетитель
  • Что предлагается и чем подтверждается результат
  • Какие блоки обязательны
  • Какие тексты, фотографии и отзывы уже готовы
  • Какие сайты нравятся и что именно в них привлекает
  • Какие ограничения есть у бренда и технической платформы
Промпт для структуры
> Прочитай бриф и материалы проекта. Сначала предложи структуру страницы: порядок блоков, задачу каждого блока и главное действие посетителя. Отдельно перечисли, каких данных не хватает. К коду переходи после моего подтверждения структуры.
Визуальная система

Выбери стиль и добавь DESIGN.md

Refero Styles содержит более 2 000 примеров дизайн-систем. У каждого примера есть машинно-читаемый DESIGN.md с описанием цветов, типографики, отступов и компонентов.

  1. Открой Refero Styles и выбери направление, подходящее аудитории и продукту.
  2. Открой DESIGN.md выбранного примера и сохрани его в корень проекта.
  3. Попроси агента проверить правила и показать, как они будут применены к странице.
DESIGN.md служит ориентиром. Логотипы, тексты, изображения и уникальные элементы чужого бренда копировать не следует.
Главный промпт
> Прочитай DESIGN.md в корне проекта и используй его как правила дизайна. Собери [тип сайта] для [аудитория и задача]. Примени skill design-taste-frontend. Сначала покажи структуру страницы и визуальное направление. К коду переходи после моего подтверждения.
Первый проход

Собери страницу и проверь содержание

После утверждения структуры агент собирает первую версию. На этом этапе проверь тексты, смысл блоков, ссылки, формы и отображение на телефоне. Декоративные эффекты пока отложи.

Промпт для сборки
> Структура утверждена. Собери первую рабочую версию по DESIGN.md. Используй реальные материалы проекта. Проверь мобильную версию, читаемость, ссылки, формы и состояния кнопок. Покажи результат и список решений, которые требуют моего подтверждения.
Проверка интерфейса

Установи Impeccable

Impeccable — набор дизайн-проверок для coding-агентов. В репозитории заявлены 1 skill, 23 команды и 59 детерминированных правил для поиска типичных проблем интерфейсов.

Установка
$ npx impeccable install

После установки перезапусти coding-агент и выполни инициализацию проекта:

Claude Code
> /impeccable init

Открыть репозиторий Impeccable

Рабочий порядок:

Команды проверки
> /impeccable critique landing
> /impeccable layout landing
> /impeccable typeset landing
> /impeccable audit landing
> /impeccable polish landing
  • critique оценивает иерархию, понятность и впечатление
  • layout исправляет сетку, отступы и визуальный ритм
  • typeset проверяет шрифты, размеры и иерархию текста
  • audit ищет проблемы адаптивности, доступности и производительности
  • polish выполняет финальную чистку перед публикацией
Финальный слой

Добавь анимации последними

Навыки Emil Kowalski помогают выбрать места для движения, проверить уже созданные эффекты и подготовить план улучшений. Устанавливай их после готовой структуры, текста, адаптивной версии и проверки интерфейса.

Установка
$ npx skills@latest add emilkowalski/skills

Открыть репозиторий Skills for Designers and Engineers

Последовательность
> Используй find-animation-opportunities и найди элементы, которым движение поможет объяснить действие или состояние.

> Используй improve-animations и составь приоритетный план улучшений.

> Используй review-animations и проверь готовые эффекты, длительность, easing, производительность и prefers-reduced-motion.
Установка навыка не гарантирует дорогой визуал автоматически. Результат зависит от брифа, выбранной системы, исходных материалов и качества проверки.
Перед публикацией

Финальная проверка

  • Главная мысль понятна на первом экране
  • Кнопки ведут по правильным адресам
  • Формы отправляют данные и показывают результат
  • Страница читается на телефоне, планшете и компьютере
  • Текст не выходит за границы блоков
  • Изображения сжаты и имеют описания alt
  • Контраст текста достаточен для чтения
  • Анимации не мешают управлению и учитывают prefers-reduced-motion
  • В исходниках отсутствуют пароли, токены и персональные данные
  • Перед публикацией сохранена резервная копия или создан коммит Git

Что важно помнить

Skills усиливают процесс

Дорогой визуал рождается из точной задачи, сильных материалов, выбранной дизайн-системы и нескольких циклов проверки. Skills помогают агенту соблюдать правила и замечать ошибки, но решение о смысле, бренде и публикации остаётся за владельцем проекта.

Команды и способы установки со временем меняются. Перед запуском сверяйся с README каждого репозитория и официальной документацией Claude Code.
