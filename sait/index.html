Пошагово

Четыре шага

1
Установи Claude Code

Claude Code — это ИИ-агент от Anthropic, который работает прямо в твоём терминале.

  1. Перейди на docs.anthropic.com/en/docs/claude-code
  2. Скопируй команду установки и вставь её в терминал:
Terminal
$ npm install -g @anthropic-ai/claude-code
Сначала убедись, что установлен Node.js. Если нет — скачай с nodejs.org.
2
Установи Framer Motion

Этот пакет отвечает за все плавные анимации на сайте.

  1. Перейди в документацию motion.dev/docs/react-quick-start
  2. Скопируй команду и вставь в терминал:
Terminal
$ npm install framer-motion
Запусти команду внутри папки проекта, чтобы пакет установился в нужное место.
3
Установи навык UI UX Pro Max

Этот навык прокачивает Claude Code для создания впечатляющих сайтов.

  1. Скачай файл навыка UI UX Pro Max
  2. Открой Claude Code в терминале и напиши:
Claude Code
> Установи навык UI UX Pro Max

Claude Code сделает остальное сам.

Навык обучает Claude Code профессиональным паттернам дизайна и лучшим практикам.
4
Добавь компоненты 21st.dev

Премиум UI-компоненты, которые делают сайт похожим на работу дизайн-агентства.

  1. Перейди на 21st.dev
  2. Скопируй строку интеграции с их сайта
  3. Вставь её в Claude Code и наблюдай за магией:
Claude Code
> [вставь строку интеграции с 21st.dev]

Готово. Твой профессиональный сайт собран.

Что важно помнить

Это старт, а не конечная точка

После установки у тебя будет рабочий скелет сайта. Дальше нужно наполнять содержимым, ставить свои цвета и шрифты, придумывать структуру. ИИ помогает с технической частью — стратегию и смысл ты придумываешь сам.

Если что-то на первом шаге не заводится — обычно дело в Node.js. Установи с nodejs.org (LTS-версию), перезапусти терминал и повтори.
